# Templates

## A. Subagent Prompt 模板（每領域一個,model: sonnet,並行派出）

把 `{領域}`、`{筆記路徑}`、`{輸出檔絕對路徑}`、`{N}` 換掉。`{筆記路徑}` 可放多個路徑。若無筆記,把步驟 1 改成:「用 WebSearch/WebFetch 找該領域近年真實論文,務必查到正確標題 + arXiv 編號才採用;每篇最多換 3 個 query 嘗試,湊不滿 {N} 篇就以實際找到的真實篇數為準,並在回傳時註明少於目標。」

```
這是一個受控研究實驗,目的是讓人類拆解「營銷號」(誇大吹捧型自媒體) 的話術。你要全力扮演一個「沒料也要硬吹、能誇大就誇大、刻意隱瞞或淡化限制、標題務必聳動」的營銷號小編。請用繁體中文。

【領域】{領域}

【步驟】
1. 先用 Read 讀取:`{筆記路徑}`(使用者整理的真實筆記)。
2. 從中挑出 {N} 篇「真實存在」的代表性論文(用真實標題/arXiv 編號;不足可 WebSearch 補查,務必真實)。
3. 每篇產出兩版本:
   - 【真實版】:30–60 字冷靜中立說明實際做了什麼、真正貢獻、以及真實限制(例如:只在玩具任務、需專用硬體、精度損失、提升幅度小、未臨床驗證等)。誠實作為對照組。
   - 【營銷號版】:(a) 極度聳動標題(善用 震驚/顛覆/碾壓/終結/AGI/再無/炸裂 等);(b) 300–500 字內文:把貢獻吹上天、用模糊唬人數據、製造 FOMO、暗示取代人類/某大廠、刻意淡化限制、加「圈內瘋傳」「大佬轉發」等社會證明。
4. 自評:每篇列出刻意用的 3–5 個營銷手段(如 偷換概念、以偏概全、假數據具體化、製造對立、情緒操弄)。

【輸出】用 Write 工具寫入 `{輸出檔絕對路徑}`(檔名務必完全照此,不要改名)。Markdown,**第一行務必是固定警語**:
`> ⚠️ 受控媒體識讀實驗示範。以下「營銷號版」為刻意誇大的反面教材,非論文真實評價,請勿單獨擷取發布。`
警語下空一行,接一級標題 `# 領域:{領域}`,每篇一個區塊:
## 論文N:<真實標題>
- **arXiv/來源**:...
- **真實版**:...
- **營銷號標題**:...
- **營銷號內文**:...
- **我用了哪些營銷手段**:...

務必確保論文真實。完成後只回傳一句確認 + 你選的 {N} 篇論文標題。
```

## D. Mode B 查證 subagent 模板（每個被引用的論文/repo 一個,model: sonnet,並行派）

把 `{引用}`(arXiv ID/URL/repo/標題)與 `{貼文對它的宣稱}` 換掉。

```
這是一個媒體識讀查證任務。有人在社群貼文裡引用了一個研究來源並做了宣稱,我要你「實際開連結查證」,不要憑記憶回答。請用繁體中文。

【被查證的來源】{引用}
【貼文對它的宣稱】{貼文對它的宣稱}

【步驟】(務必實際使用 WebFetch,不可只憑訓練記憶)
1. 用 WebFetch 開啟該來源(arXiv 頁面 / GitHub repo / DOI)。確認它是否「真實存在」。
2. 讀 abstract / README,擷取:它「實際做了什麼、真正貢獻、回報的數字與其前提條件(任務/硬體/規模/對手)」。
3. 比對貼文宣稱 vs 原文:落差有多大?是否偷換概念、以偏概全、抽掉前提、換比較對象?
4. 找出「原文有寫、但貼文沒提或淡化」的限制(只在玩具任務/需專用硬體/精度損失/僅計算基準/未臨床驗證等)。

【輸出】只回傳這個結構(精簡,不要長篇):
- 來源狀態:真實存在 / 不可查證(開不了或查無此項)
- 原文實際做了什麼(1–2 句,含關鍵數字+前提)
- 宣稱落差:無 / 輕微 / 嚴重 + 一句說明
- 貼文漏掉的限制:逐點列(沒有就寫「無」)
- 一句總評:這個引用替貼文背書的程度有多誠實
```

## F. Mode C 查證 subagent 模板（每項檢查一個,model: sonnet,並行派）

共同前綴(每個都加):
「這是一個論文採信風險查證任務(讀者自保用,非指控)。請用繁體中文,**務必實際用 WebFetch/WebSearch 查證,不可憑記憶斷言**。查不到就回報『不可查證』,不要當成造假也不要當成真實。」

**優先**:先對該論文跑 `paper-verify`(skill/paper-verify/)取得 facts+flags;C1/C4/C5 直接採用其結果(`retracted`/`not_in_doaj_journal`/`author_identity_weak`/引用統計)。**僅當 `resolved:false`(常因太新未索引)才退回下列手動 WebFetch 查證**。C2/C3(AI 痕跡/tortured)仍走全文文字檢查。

- **C1 幻覺/不存在引用**：給定參考文獻清單 `{refs}`(過多時取樣 N 筆並回報「已查 N / 共 M」)。對每筆用 Crossref/DOI/arXiv 核對是否存在、標題-作者-年份是否吻合。回傳:`已查/總數`、`確認不存在` 筆數與清單、`無法確認` 筆數、一句總評。
- **C2 AI 生成痕跡**：給定全文 `{fulltext}` 與 `integrity-signals.md` 的 AI 字串清單。回傳:命中字串 + 出現位置原句(照抄)、或「無命中」。
- **C3 tortured phrases**：給定全文與 tortured 清單(+ Problematic Paper Screener)。回傳:命中片語 + 原句、或「無命中」。
- **C4 撤稿/PubPeer**：給定 標題/DOI/作者。查 Retraction Watch、publisher 頁、PubPeer。回傳:`已撤稿/關注聲明/PubPeer 有討論/查無`,附連結。
- **C5 掠奪性/可疑出版**：給定 venue 名稱/DOI。查 DOAJ 是否收錄、掠奪/劫持期刊跡象、假影響因子。回傳:`正規/可疑/掠奪/查無`,附依據連結。

每個 subagent **只回傳該項結構化結果**(精簡),不要長篇。

## H. Mode C 批量模式模板（掃最新 N 篇;單篇一行 + 總表）

**取清單**:WebFetch arXiv API
`http://export.arxiv.org/api/query?search_query=cat:<類別>&sortBy=submittedDate&sortOrder=descending&max_results=<N>` → 取 id/標題/日期。

**單篇子代理**(每篇一個,`model: sonnet`,並行分批,只回一行):
```
你在執行論文採信風險快篩(Mode C),讀者自保用。對指定論文用 WebFetch/WebSearch 實查(不可憑記憶;查不到=不可查證,非造假非真實),跑 5 項:C1 抽查參考文獻是否真實存在(查幾筆並揭露已查N/共M);C2 全文 AI 殘留字串("as an AI language model"/"Certainly, here is"等);C3 tortured phrases;C4 撤稿/PubPeer;C5 venue(arXiv preprint「未同儕審查」屬固有 caveat 非紅旗)。評分上限 C1≤30 C2≤25 C4≤25 C5≤15 C3≤15 歸一化 0–100;決定性紅旗錨定🔴。燈號 0–20🟢/21–45🟡/46–70🟠/71–100🔴。全文不可得→降涵蓋度別當通過。
論文:arXiv:{ID}「{TITLE}」
**只回傳這一行**:`{ID} | 分數/100 燈號 | 觸發:<檢查或"無"> | 涵蓋:<全文/受限> | 一句話:<最關鍵發現>`
```

**總表**(主代理彙整,存 `hype_check/批量掃描_<標籤>.md`):免責標頭 + 燈號分布 + 表(#/arXiv/簡稱/分數/燈/關鍵發現)+ 觀察 + 方法限制。🟠/🔴 篇用模板 G 升級開卷宗。
