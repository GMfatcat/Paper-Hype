# Examples — experiment data

> ⚠️ **These files contain deliberately fabricated clickbait.** Every piece below is a *controlled media‑literacy demo*: a real paper rewritten into an exaggerated "營銷號 (hype account)" version, paired with an honest control. The hype versions are **teaching counter‑examples, not real evaluations** — do not extract and republish them as takes on the papers.

This is the data behind the skill: **25 AI domains × ~3 papers = 75 hype pieces**, produced across three batches and then analyzed. Every cited paper is real (titles + arXiv IDs verified).

## What each file contains
Per paper, a block with:
- **arXiv/來源** — the real source link
- **真實版** — honest plain‑language summary, *including the real limitations* (the control)
- **營銷號標題 / 內文** — the deliberately exaggerated title + body
- **我用了哪些營銷手段** — self‑labeled list of the manipulation tactics used

Each batch folder also has a `00_analysis_report.md` scoring every piece and extracting the patterns.

## The payoff
`cross-batch-playbook.md` consolidates all three batches into a single anti‑hype field guide: the iron rules, the tactic taxonomy, the high‑frequency keywords and sentence templates, and a Threads/X red‑flag checklist. **If you only read one file, read that one.**

### Cross‑batch findings (short version)
- Hype is **template‑driven** and decoupled from a paper's actual merit — a survey, a benchmark, even a negative result all get spun into "breakthrough."
- The hardest trick to catch is **real numbers with the premises stripped out** ("19 neurons beat billion‑param models" — true, but only for lane‑keeping).
- **Reverse‑marketing** (debunking / "your AI is lying to you") is the same traffic business as hyping.
- The closer a field gets to money and to personal safety, the more extreme the emotional hooks (niche → numbers games; mainstream → anthropomorphizing + nationalism; hot → reversing good news into horror + attacking your job/health).
