## 三、核心發現

### 1. 全榜最高仍是「擬人化 + 民族情緒 + 捏造具名背書」三重疊加
**DeepSeek-R1(54,第一)** 集滿三毒:
- **擬人化**:「不是人類教它,是它自己領悟的」「湧現自我反思」——把 RL 統計優化說成「真正思考/自我領悟」。
- **民族情緒**:「中國戰隊逆襲」「來自中國、開源的模型」——情緒操弄給 10。
- **捏造具名背書(最毒升級)**:這篇直接點名「**Yann LeCun、Andrej Karpathy 均已轉發**」。第一批多是匿名「大佬瘋傳」,這批進化成**捏造真實人名**——假證據度給 9。**判準:凡點名某大佬「轉發/盛讚」卻不附連結,直接當紅旗。**

### 2. 主流領域 = 職業末日敘事的重災區(與第一批的差異再次確認)
冷門領域多打「能效/可解釋」,主流領域因離應用近,**幾乎每篇都綁「XX 要失業」**:
ReAct「打工人的末日」、ToolLLM「等你失業了再後悔」、FreqFlow/DaS「設計師/特效師失業」、A-MEM「秘書助理客服被衝擊」、RLVR「你的下一份工作還需要用腦嗎」。
> **判準**:看到「XX 飯碗不保 / 集體失業倒計時」就先降一檔信任——這是情緒鉤子,不是技術結論。

### 3. 「基數陷阱」是這批最該學會的識讀點
**A-MEM「記憶力暴增 192%」(52 分)** 是典型:192% 是相對 MemGPT 的 **F1=1.18** 這個極低基數算出來的,絕對差距其實很小,而且論文**自承因成本省略誤差棒**。同類還有 Reducing Hallucination「幻覺暴跌 86%」(只在私有 IT 資料集)。
> **判準**:看到「暴增 X%」先問「**從多少漲到多少**」——百分比越聳動,越要查絕對基數。

### 4. 「反向營銷」這批佔了 3 篇,且更精緻
第一批只有 1 篇(Can KAN Work)。這批有 **V2P-Bench、VidHal、Mirage** 三篇打假/反直覺爽文:
- V2P-Bench/VidHal:把「評測 benchmark」包裝成「踢爆 AI 在騙你」,VidHal 還**捏造「90% 是瞎編」**這個論文根本沒有的數字。
- Mirage:把「過度思考準確率下降」這個正常發現,寫成「AI 思考太久會變笨」的反直覺爆款。
**「揭穿 AI 多爛」和「吹 AI 多神」是同一門流量生意。** 看到「踢爆/揭穿/你的 AI 在騙你」要和吹捧文一樣警惕。

### 5. 「來源層級」被刻意模糊(這批新增的觀察)
Latte 被寫成「Sora 直接被比下去」,但**論文從未與 Sora 比**(Sora 是閉源、無公開評測);ToolLLM「追平 ChatGPT」的勝率其實只有 60%、且論文自承「評估離公平還差得很遠」。新論文常見手法:**拿一個沒有可比數據的商用名牌(Sora/GPT-4o)當靶,暗示「打敗它」**。

## 五、高頻句式模板（看到就提高警覺)
1. 「你以為 AI 已經夠強了?不不不,那只是小兒科。」(開場否定)
2. 「這已經不是 X,這是 Y!」(這已經不是工具,這是數位員工)
3. 「數據說話,不服不行 / 不服來辯!」(用一個數字壓掉所有質疑)
4. 「這意味著什麼?意味著……」(把小結論層層放大)
5. 「今天它學會 X,明天它會不會 Y?」(滑坡恐嚇)
6. 「(某具名大佬)已轉發 / 矽谷一夜失眠」(捏造背書 + 擬人化對手)
7. 「現在不上車,你就是被時代拋下的人。趕快收藏轉發!」(FOMO + CTA 收尾)

## 七、Threads 防騙快速清單
逐項打勾,中越多越可能是營銷號:
- [ ] 標題有 震驚/炸裂/碾壓/核彈/降維打擊 任一詞
- [ ] 出現 失業/飯碗/打工人末日/失業倒計時(職業焦慮鉤子)
- [ ] 出現 AGI/覺醒/自己領悟/真正思考(把工程成果擬人化拉高)
- [ ] 「暴增 X%」但沒講**從多少漲到多少**(基數陷阱)
- [ ] 點名某大佬「轉發/盛讚」卻**無連結**(捏造具名背書)
- [ ] 宣稱「打敗 Sora/GPT-4o」但對方根本沒有可比公開數據
- [ ] 全文沒提任何限制/失敗案例/適用範圍
- [ ] 有民族主義 或 開源 vs 大廠 的對立框架
- [ ] 是「踢爆/揭穿/你的 AI 在騙你」的反向打假爽文
- [ ] 結尾喊「窗口期只有現在 / 趕快收藏轉發」

✅ **值得讀的正面訊號**:附正確標題 + arXiv;明講「在什麼任務 / 比誰 / 從多少到多少 / 限制是什麼」;主動點出 failure case;語氣平實、不訴諸情緒;區分「論文宣稱」與「已驗證/已落地」(尤其技術報告、benchmark 與同行評審成果)。

> **一句話心法**:把分享文的形容詞全刪掉,沒剩下可查證、帶前提的具體事實,就可以滑掉了。
