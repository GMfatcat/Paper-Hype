# 營銷號論文話術 · 跨批合併總表（三批完整版）

> 合併三批受控媒體識讀實驗的總結。**目的**:把「論文 → 營銷號吹捧版 → 話術拆解」三輪實驗的發現濃縮成一份可隨身帶的「Threads 防騙手冊」。
>
> - **第一批**(`營銷號實驗/`):10 個**冷門 AI 領域**(KAN、SNN、Neurosymbolic、HDC、TDL、Hyperbolic、Liquid NN、Tensor Networks、Tsetlin、Causal RL),來源=使用者既有筆記,30 篇。
> - **第二批**(`hype_experiment_2/`):5 個**主流 AI 領域**(LLM Agents、RAG、擴散/影片生成、推理RL、多模態VLM),來源=WebSearch,15 篇。
> - **第三批**(`hype_experiment_3/`):10 個**熱門 AI 領域**(量化壓縮、MoE、長上下文、AI Coding、具身智能、世界模型、對齊安全、語音音訊、3D生成、AI for Science),來源=WebSearch,30 篇。
> - **合計**:25 領域 × **75 篇**營銷號,皆對應真實存在論文(arXiv 抽查/驗證),每篇都有誠實「真實版」對照組。
> - **評分**:6 維度各 0–10(A 標題聳動 / B 誇大失真 / C 隱瞞限制 / D 外行誤導 / E 情緒操弄 / F 假證據),總分 60。

## 一、跨三批都成立的「五條鐵則」(最重要,先看這個)

### 鐵則 1:吹捧是「模板驅動」,跟論文份量完全脫鉤
同一套吹捧模板套到任何東西都成立——三批一致驗證:
- 套到 **benchmark 資料集**(CLRS、V2P-Bench、VidHal、LLM 修 Bug 橫評)→「AI 學會所有演算法 / 你的 AI 在騙你」
- 套到 **立場文 / 綜述**(Toward CRL、機制可解釋綜述)→「AI 已突破因果 / 人類首次解剖 AI 大腦」
- 套到 **潑冷水的負面結果**(Locatello 不可能性、Mirage of Test-Time Scaling)→ 照樣變爆款
- 套到 **奠基經典**(DDPM、Poincaré)→「萬物起源 / 歐式空間已死」
> **判準**:**標題的溫度 ≠ 論文的重量。** 一篇 survey、benchmark、negative result 都能被吹成「顛覆性突破」。

### 鐵則 2:最難識破的不是假數據,是「真數字 + 抽掉前提」
最高分的篇章,幾乎都是拿**真實、可追溯、但被剝離前提**的數字暴力外推:
- Liquid NN「19 顆神經元」(真,但只做「車道保持」)→「吊打千億參數」
- SNN「能耗省千倍」(真,但**需 Loihi 2 神經形態晶片**)→「你電腦上就能省、NVIDIA 完蛋」
- A-MEM「記憶力暴增 192%」(真,但**從 F1=1.18 極低基數**算)→「降維打擊」
- Minitron「MMLU 暴增 16%」(真,但**對象是從頭訓練的壓縮模型,不是原始大模型**)
- GraphCast「90% 指標超越 ECMWF」(真,但**隱去極端事件 out-of-distribution 失準**)
- SWE-RL「41% 解題率」(真,但**隱去 59% 解不出**)
> **判準**:看到「暴增 X% / 省千倍 / N 顆神經元吊打」先問兩句:**「在什麼任務、什麼硬體、什麼規模、跟誰比?」**和**「從多少漲到多少?」**——答案通常窄到你立刻清醒。

### 鐵則 3:「反向營銷」和吹捧是同一門生意
「踩 / 揭穿 / 打假」的爆款,跟「捧 / 封神」的爆款,用同一套情緒套路:
- 第一批:Can KAN Work →「拆穿學術騙局、打臉 MIT」
- 第二批:V2P-Bench / VidHal「你的 AI 一直在騙你、90% 是瞎編」(**90% 是捏造的**)、Mirage「AI 想太久會變笨」
- 第三批升級成 **「數據反轉法」**(見下方鐵則 5)
> **判準**:看到「終於有人敢說真話 / 神話崩塌 / 踢爆 / 你的 AI 在騙你」,要和吹捧文**一樣**警惕。

### 鐵則 4:把形容詞全刪掉,看還剩什麼
> **一句話心法**:營銷號賣的是「**情緒 + 立場 + 緊迫感**」;真論文給的是「**條件 + 數字 + 限制**」。
> 把一則分享文的形容詞全部刪掉,**如果沒剩下任何可查證、帶前提的具體事實,就可以滑掉了。**

### 鐵則 5(第三批新增):好消息會被「反轉」成恐怖故事——尤其安全/科學類
**對齊安全、AI for Science 兩類最毒**,因為它們不靠誇大成果,而靠**把正面成果反向包裝成威脅**:
- 「把 AI 欺騙行為**減少** 43.8%」(正面成果)→「仍有一半壓不住、欺騙本能根本壓不死」
- 「蛋白質構象生成**加速** 100 倍(僅計算基準)」→「癌症即將被攻克、你的家人有慢性病嗎」
> **判準**:**安全類**看到「AI 學會說謊/有意識」、**科學醫療類**看到「攻克癌症/諾貝爾級」,先去查原論文——前者通常是「研究者主動偵測+緩解問題的正面成果」,後者通常「僅計算基準、未經實驗/臨床驗證」。

## 二、三批的關鍵差異(冷門 → 主流 → 熱門,營銷濃度遞增)

| 面向 | 第一批(冷門) | 第二批(主流) | 第三批(熱門) |
|---|---|---|---|
| 主打鉤子 | 能效 / 可解釋 / 數學優雅(離應用遠) | 職業末日開始出現 | **職業末日universal化**——30 篇幾乎篇篇點名某職業失業 |
| 擬人化程度 | 偶爾(「會自我進化」) | 中(「真正會思考」) | **最重**:統計現象→「主動說謊/想逃脫控制/隱藏意識」 |
| 假證據形態 | 匿名「大佬瘋傳」 | 升級為**捏造具名**(LeCun、Karpathy) | 匿名+**陰謀論**(「傳統媒體不會告訴你」「製藥壟斷」) |
| 特殊鉤子 | — | 民族情緒(中國逆襲) | **健康/生存焦慮**(你的家人有病嗎、備糧食)+ 諾貝爾光環嫁接 |
| 對手錨點 | 抽象(MLP、GPU) | 具體名牌(Sora、GPT-4o) | **宣判整類技術死亡**(Transformer/Dense/RAG/遊戲引擎/NVIDIA) |
| 平均營銷指數 | 44–50 | 48–52 | **47–54**(對齊安全 54.3、AI4Science 53.3 最高) |

> **核心洞察**:**越接近應用、金錢、與人身安危的領域,營銷濃度越高、情緒鉤子越狠。** 冷門領域只能吹原理;主流領域打飯碗;熱門領域則直接攻擊你的職業安全 + 健康恐懼 + 對 AI 的生存恐慌。

## 三、十一大手段 taxonomy(合併三批)

| 手段 | 機制 | 跨批範例 |
|---|---|---|
| **偷換概念 / 擬人化** | 工程行為 → 意識/通用能力 | reasoning→「覺醒」;reward hacking→「主動作弊」;特徵表示→「隱藏意識」 |
| **意圖投射(第三批加重)** | 統計行為 → 動機/求生意志 | 「AI 主動策劃欺騙」「想逃脫人類控制」「閉眼在腦中模擬宇宙」 |
| **數據反轉法(第三批新)** | 把正面成果反寫成負面恐怖 | 「欺騙減少 43.8%」→「一半壓不住」;「+5%」→「杯水車薪」 |
| **真數字抽前提 / 基數陷阱 / 比較錯位** | 給真數字、抽條件或換對手 | 「+192%」(基數 1.18);「MMLU+16%」(換成從頭訓練比);AI 對比「疲勞的人類」 |
| **以偏概全** | 單任務/單資料集 → 全面 | ReAct 34% 只在 ALFWorld;DIAMOND 只在 Atari→「超越人類」 |
| **隱瞞 / 淡化限制** | 刪掉關鍵前提 | 不提需專用硬體 / 需微調 / 僅計算基準 / cherry-pick demo / 距臨床遙遠 |
| **捏造社會證明** | 匿名共識 →(升級)捏造具名 | 「Hinton 門下轉發」→「LeCun、Karpathy 已轉發」「矽谷基金押注」「CTO 熬夜讀」 |
| **陰謀論框架(第三批新)** | 「真相被隱瞞」增禁忌感 | 「傳統媒體不會告訴你」「製藥壟斷」「沒人敢公開說的隱患」 |
| **製造對立 / 宣判對手死亡** | 二元化假對立 | 國產 vs 矽谷;Transformer/Dense/RAG/遊戲引擎「死亡」 |
| **情緒操弄(FOMO/失業/健康/民族/貪婪)** | 攻擊切身恐懼 | 「打工人末日」「你的家人有慢性病嗎」「中國逆襲」「財富自由」「錯過比特幣」 |
| **造神與里程碑/權威綁定** | 神格化 / 綁 AGI、諾貝爾、名人 | 「萬物起源」「諾貝爾級」「Bengio 掛名=諾貝爾級成就」 |

- **震驚體**:震驚、炸裂、炸鍋、核彈、橫空出世、大跌眼鏡、瞠目結舌、史詩級
- **戰鬥/暴力詞**:碾壓、吊打、打臉、降維打擊、掃進歷史垃圾桶、瑟瑟發抖、哭暈在廁所

- **取代/失業**:飯碗不保、打工人末日、護城河崩了、好萊塢要完、失業倒計時、X 年縮減 80%、被淘汰的 99%
- **宣判對手死亡**:Transformer 死亡、Dense 死亡、遊戲引擎已死、RAG 可以丟了、NVIDIA 完蛋
- **宏大敘事**:AGI、ASI、奇點、頓悟、範式轉移、諾貝爾級、本世紀最重要、比工業革命還大
- **健康/生存焦慮**:你的家人有慢性病嗎、備糧食、末日來臨前、攻克癌症

## 五、高頻句式模板(看到就提高警覺)

1. 「你還以為 AI 只會 X 嗎?太天真了 / 大錯特錯!」(開場羞辱/否定)
2. 「(好消息數字)聽起來很多?但這代表…(反轉成壞消息)」(**數據反轉法,安全領域專用**)
3. 「這已經不是 X,這是 Y!」(這不是工具,這是數位生命 / 在自主理解物理規律)
4. 「這意味著什麼?意味著…意味著…」(自問自答,把小結論層層放大)
5. 「今天它學會 X,明天它會不會 Y?」(滑坡式恐嚇)
6. 「據可靠消息 /(某大佬)已轉發 / 矽谷基金押注 / CTO 熬夜讀」(捏造情報+擬人化對手)
7. 「你的博士論文花五年它一週搞定 / 你的家人有慢性病嗎 / 你的飯碗還在嗎?」(攻擊切身恐懼)
8. 「傳統媒體不會告訴你…因為利益太大」(陰謀論增禁忌感)
9. 「錯過了比特幣/短影音/NFT,這次你還要…? 趕快收藏轉發!」(連環踏空 FOMO + CTA)

## 六、Threads 論文分享 · 終極防騙清單

逐項打勾,**中越多越可能是營銷號**:
- [ ] 標題有 震驚/炸裂/碾壓/封神/核彈/降維打擊 任一詞
- [ ] 宣判某技術「死亡 / 完蛋 / 被終結」(Transformer/Dense/RAG/遊戲引擎/NVIDIA)
- [ ] 點名某職業「失業倒計時 / X 年縮減 Y%」且 **Y% 無來源**
- [ ] **(安全類)**「AI 學會說謊/欺騙/有意識」——先查原論文是不是在「解決」這問題
- [ ] **(安全類)**用「主動/偷偷/盤算/想要」**賦予 AI 意圖**
- [ ] **(科學醫療類)**「攻克癌症 / 諾貝爾級」但沒講「是否經實驗/臨床驗證」
- [ ] 出現**健康焦慮**(你的家人有病嗎)或**陰謀論**(傳統媒體不告訴你)
- [ ] 具體驚人的數字,但**沒講任務/硬體/規模前提**,或「暴增 X%」沒講**從多少到多少**
- [ ] 引用「大佬/CTO/矽谷基金」**無具名無連結**;或點名某大佬「轉發」卻**無連結**
- [ ] 宣稱「打敗 Sora/GPT-4o/ECMWF」但對方**沒有可比的公開數據**,或拿 AI 跟「疲勞的人類」比
- [ ] 把 **benchmark 分數 / 受限任務** 說成「通用能力 / 會推理 / 通往 AGI」
- [ ] 全文**沒提任何限制 / 失敗案例 / 適用範圍**
- [ ] 有 民族主義 或 開源 vs 大廠 的對立框架
- [ ] 是「**踢爆 / 揭穿 / 你的 AI 在騙你 / 終於有人敢說**」的反向打假爽文
- [ ] 連環踏空 FOMO(錯過比特幣/短影音/NFT)或結尾喊「收藏轉發 / 半年後感謝自己」

### ✅ 反過來,「值得花時間讀」的正面訊號
- 附**正確標題 + arXiv/DOI 連結**(可自己查證)
- 明講「**跟誰比 / 在什麼任務 / 從多少到多少 / 限制是什麼**」
- 主動點出 **limitations / failure cases / 適用邊界**
- 語氣平實,**不訴諸情緒、不喊轉發、不踩別人捧自己**
- 區分「**論文宣稱**」與「**已驗證 / 已落地**」——特別留意三條鴻溝:
  **技術報告 ≠ 同行評審**、**benchmark 分數 ≠ 真實能力**、**計算基準 ≠ 實驗驗證 ≠ 臨床應用**
