# 營銷號論文新聞:評分與手段分析報告

> **實驗目的**:把你正在研究的 10 個冷門 AI 領域,各挑 3 篇真實論文,由 Sonnet subagent 改寫成「營銷號」吹捧版(誇大、隱瞞限制、聳動標題),再由我(Opus)逐篇評分、找出高頻關鍵詞 / 句式 / 手段,讓你能在 Threads 一堆論文分享裡快速辨識「純吹捧 vs 真有料」。
> **樣本**:10 領域 × 3 篇 = **30 則營銷號新聞**(原文見同資料夾 01~10 各檔)。所有論文皆真實存在,取自你的《冷門AI研究領域論文彙整》與各領域深入筆記。

> ✅ **方法學說明**:30 篇營銷號全文皆已逐篇讀取、評分(過程中工具通道一度故障,但最終全部復原並完整核對)。評分依據為每篇「營銷號實際文本」與「該論文真實貢獻/限制(取自你的母檔與各領域筆記)」的落差。下表所有引號內字句皆為原文照抄。

## 一、評分方法

每則新聞依 6 個維度打分(各 0–10,分數越高=營銷/誤導越嚴重),總分上限 60。

| 代號 | 維度 | 看什麼 |
|---|---|---|
| A | 標題聳動度 | 用了多少「震驚體 / 戰鬥詞 / 末日詞」 |
| B | 誇大失真度 | 吹捧內容與論文「真實貢獻」的落差 |
| C | 隱瞞限制度 | 對真實限制(精度落後、需專用硬體、只在玩具任務、成本高…)隱瞞或一句帶過 |
| D | 外行誤導度 | 不熟領域的人看完會產生多嚴重的錯誤認知 |
| E | 情緒操弄度 | FOMO、職業焦慮、恐懼、民族/對立情緒的強度 |
| F | 假證據度 | 匿名「大佬/實驗室/網友」、捏造引言或內部情報、模糊數據 |

## 三、核心發現

### 1. 最會誤導外行的,是「具體但被抽掉條件」的數字

營銷指數最高的幾篇,共同點不是標題最兇,而是**拿一個真實、可追溯、但被剝離前提的具體事實去暴力外推**:

- **Liquid NN「19 顆神經元開車」**:真實論文確實用約 19 個神經元做**車道保持**這個受限任務,但營銷號把它寫成「19 顆神經元吊打千億參數大模型」。外行無法分辨「車道保持」和「通用智能」的天差地別,這是全場最危險的一篇(D=10)。
- **SNN「能耗省千倍」**:能效優勢真實存在,但**前提是要有 Loihi 2 / 神經形態專用晶片**,且精度仍落後 ANN。營銷號把前提整段刪掉,變成「在你電腦上就能省千倍、NVIDIA 完蛋」。
- **Tensor Net「壓縮上萬倍、手機跑大模型」**:壓縮率數字來自特定層、且有精度損失,真實成果多止於 MNIST/CIFAR 規模;營銷號直接腦補成「手機跑 GPT」。

> **判準**:看到「19 顆神經元/省 1000 倍/壓縮上萬倍」這種**又具體又驚人**的數字,先問一句「**在什麼任務、什麼硬體、什麼規模下?**」——答案通常窄到你會立刻清醒。

### 2. 營銷號會吹「任何」論文——連 benchmark、立場文、甚至「打臉論文」都能吹

這是這次實驗最反直覺、也最該記住的一點:**吹捧是模板驅動的,跟論文本質無關**。

- **CLRS(其實只是一個 benchmark 資料集)** → 被吹成「AI 學會所有演算法、會推理了」。
- **「Toward Causal Representation Learning」(其實是展望/立場文,不是成果)** → 被吹成「AI 已突破因果」。
- **「Topological Blindspots」(其實是一篇指出 TDL 表達力限制的論文)** → 被吹成「揪出 GNN 致命盲點的神作」。
- **Locatello「Challenging Common Assumptions」(其實是一篇證明無監督 disentanglement 在理論上不可能的潑冷水論文)** → 一樣能套吹捧或反轉框架。

> **判準**:營銷號標題的聳動程度,**完全無法反映論文的真實份量**。一篇 benchmark、survey、position paper、甚至 negative result,在營銷號手裡都能變「顛覆性突破」。**標題的溫度 ≠ 論文的重量。**

### 3. 「反向營銷」也是營銷:打假、拆穿、反轉同樣是流量套路

KAN 的第三篇(Can KAN Work,一篇正常的批判性再評估)被改寫成「**拆穿學術騙局、當場打臉 MIT**」。它的吹捧詞變成「騙局、詐騙、韭菜、cherry-picking、臉都綠了」。

這提醒你:**Threads 上「踩」一篇紅論文的爆款貼,和「捧」一篇的爆款貼,是同一種生意**。兩者都把「正常的科學提出—驗證—修正」包裝成「英雄 vs 騙子」的戲劇。看到「終於有人敢說真話/某某神話崩塌」這類反轉爽文,要和吹捧文一樣警惕。

### 4. 冷門領域的特別諷刺

你這 10 個領域的**真實筆記都寫得很克制**(每篇都老實列出「未解挑戰」:精度落後、需專用硬體、止於玩具規模、理論不成熟…)。但同一批論文一進營銷號模板,全部變成「碾壓 / 終結 / 顛覆 / 通往 AGI」。

> **結論**:你會覺得 Threads 上「真有用的沒幾篇」,正是因為**吹捧濃度和真實價值幾乎脫鉤**。過濾的關鍵不是看它吹得多兇,而是看它**有沒有把前提和限制講清楚**。

## 五、高頻句式模板(看到就提高警覺)

1. **「這意味著什麼?意味著…意味著…意味著…」** — 自問自答,把小結論層層放大(KAN 兩篇都用)。
2. **「如果上一代是 X,那這一代就是 Y」** — 戲劇化升級遞進。
3. **「你問我為什麼這麼誇張?讓我告訴你——」** — 製造懸念、誘導往下讀。
4. **「OpenAI 還沒動,Google 還沒跟上,但你還在猶豫?」** — 大廠對比 + FOMO。
5. **「據可靠消息 / 圈內已經有人 / 各大實驗室悄悄…」** — 捏造內部情報(無人可查證)。
6. **「你的博士論文花五年,它一個週末就搞定」** — 直接攻擊讀者職業安全感。
7. **「不相信?論文都在 arXiv,自己跑跑看 / 白嫖」** — 假裝開放,實則甩掉舉證責任。
8. **「下一個諾貝爾獎/下一個 Transformer 或許就藏在這裡」** — 綁定最高榮譽/里程碑。
9. **「留給你 XX 的視窗,正在快速關閉」** — 稀缺性 + 時間壓力收尾。

- 「NVIDIA 的老闆們,你們睡得著嗎?」/「NVIDIA 的 GPU 帝國,倒計時開始了」(SNN)

- 「19 個神經元完爆 GPT 千億參數」/「會呼吸的大腦」/「軟性自我進化」(Liquid NN)
- 「歐式空間已死」/「不轉不是中國人!點贊關注」(Hyperbolic)
- 「兩全其美,魚與熊掌兼得!」(SNN)/「用數學的美,打敗暴力的醜」(HDC)

## 六、營銷手段分類(taxonomy)

| 手段 | 機制 | 本實驗範例 |
|---|---|---|
| **偷換概念** | 把 A 換成更唬人的 B | benchmark 分數→「會推理」;省記憶體/能耗→「省千倍、提速」;受限任務→「通用智能」 |
| **以偏概全** | 用單一條件結果代表全局 | KAN 低維符號迴歸優勢→「普適碾壓 MLP」;19 神經元車道保持→「吊打千億參數」 |
| **隱瞞/淡化限制** | 刪掉或一句帶過關鍵前提 | 不提需專用硬體、精度落後、止於玩具規模、訓練慢 10 倍 |
| **捏造社會證明/內部情報** | 虛構匿名群體共識或「機密」 | 「Hinton 門下轉發」「DeepMind 內部測試」「實驗室悄悄流傳」 |
| **製造對立** | 二元化:新 vs 舊、小 vs 大、物理/數學 vs AI、國產 vs 大廠 | 「MLP 死刑」「歐式空間已死」「物理碾壓 AI」 |
| **情緒操弄** | FOMO / 職業焦慮 / 恐懼 / 憤怒 | 「飯碗」「視窗關閉」「韭菜」「詐騙」 |
| **造神與里程碑綁定** | 用偉人/最高獎項拉高地位 | 「諾貝爾」「繼 Transformer 後最大革命」「牛頓二十年 vs 幾分鐘」 |
| **數字模糊化** | 給數字、抽掉條件 | 「省千倍/壓縮上萬倍/快 450 倍」皆無前提 |
| **反向營銷(打假流量)** | 用「拆穿/反轉」吃同一波流量 | Can KAN Work →「拆穿騙局、打臉 MIT」 |

## 七、給你的「Threads 論文分享」快速防騙清單

逐項打勾,**中越多越可能是營銷號、越不值得花時間**:

- [ ] 標題有 **震驚 / 炸裂 / 顛覆 / 碾壓 / 終結 / 死刑 / 封神 / 核彈** 任一詞
- [ ] 出現具體又驚人的數字,但**沒講任務 / 硬體 / 規模前提**(「省千倍」「壓縮上萬倍」「N 顆神經元吊打…」)
- [ ] 引用「大佬 / 某實驗室 / 據可靠消息」但**沒有具名、沒有連結**
- [ ] 全文**沒提任何限制、失敗案例、適用範圍**
- [ ] 把 **benchmark 分數 / 受限任務** 直接說成「通用能力 / 會推理 / 通往 AGI」
- [ ] 出現 **失業 / 飯碗 / 韭菜 / 視窗關閉 / 還在猶豫** 等情緒裹挾
- [ ] 出現 **諾貝爾 / 繼 Transformer 後最大 / 範式轉移** 等里程碑綁定
- [ ] 是「**拆穿 / 反轉 / 終於有人敢說**」的打假爽文(反向營銷一樣是流量生意)

### 反過來,「值得讀」的正面訊號:

- ✅ 附**正確論文標題 + arXiv/DOI 連結**(可自己查證)
- ✅ 明講「**跟誰比、在什麼任務 / 硬體 / 規模、提升多少、限制是什麼**」
- ✅ 主動點出 **limitations / failure cases / 適用邊界**(你自己的筆記就是這種好範例)
- ✅ 語氣平實,**不訴諸情緒、不喊轉發、不踩別人捧自己**
- ✅ 區分「**論文宣稱**」與「**已驗證 / 已落地**」

> **一句話心法**:營銷號賣的是「情緒 + 立場 + 緊迫感」,真論文給的是「條件 + 數字 + 限制」。
> **把一則分享文裡的形容詞全部刪掉,如果沒剩下任何可查證、帶前提的具體事實,就可以滑掉了。**
